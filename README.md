# Natural Harmonics

A tone and its first 15 natural harmonics, each on its own fader, played in the browser with the Web Audio API.

Live: https://pteroscillator.github.io/natural-harmonics/

Browsers tested: Safari and Firefox on macOS, Safari on iPhone

Web Audio behaves differently on Safari and iOS. On iOS, the sound plays even with the silent switch on (Safari 16.4 or later).
